# 은호 MovingVine

S1_Vine 원본을 상속한 Prefab Variant입니다. 플레이어가 가까워지면 한 번 위로 올라가며, 올라간 위치를 유지합니다. 재시작하면 원위치로 돌아오고 다시 접근 시 동작합니다.

## 배치와 설정
- 집 밖(S1) 맵의 Hierarchy에서 내 Map 아래로 끌어 넣습니다.
- 기본 Y, Scale 1, Z 0을 유지하고 X만 옮깁니다.
- Trigger Distance: 플레이어와의 가로 거리. 기본 2유닛 이하에서 상승 시작합니다.
- Rise Height: 상승 높이. 기본 2.5유닛입니다.
- Rise Duration: 상승 시간. 기본 0.75초입니다.
- Scene에서 선택하면 노란 상승 경로와 청록색 접근 기준선이 표시됩니다.
- Hazard/Trigger 판정과 파괴 불가 규칙을 유지합니다. 거대화로 부술 수 없습니다.
- Running 중에만 StageTime 기준으로 상승하며 사망/클리어 중 자체 이동은 멈춥니다.
- 재시작은 상승 상태와 타이밍을 초기화합니다.

## 작업 규칙
원본 팔레트/StageRig를 수정하거나 Overrides > Apply All을 누르지 않습니다. Play를 끄고 값을 변경한 뒤 저장합니다. 새 파일과 .meta를 함께 버전 관리합니다.

## 플레이 확인
접근 거리와 상승 시간을 조절해 Vine이 올라간 아래쪽으로 통과하는 구간을 만듭니다. 가속 상태에서도 충돌 전에 충분히 올라가는지, 감속 중 추격 쿠키에 잡히지 않는지 직접 클리어해 확인합니다. 기본 수치는 초안입니다.

## FireLong 버전
- 은호_MovingFireLong.prefab은 S3_FireLong을 상속한 Variant입니다. 오븐(S3) 맵의 내 Map 아래에 배치합니다.
- 검증된 EhMovingVine 동작을 공유합니다. 가로 거리 2유닛 이하에서 0.75초 동안 2.5유닛 상승하며 재시작할 때만 내려옵니다.
- FireLong 원본의 그림, 기본 높이, Scale, Trigger 및 파괴 불가 판정을 유지합니다.
- 맵에 배치한 뒤 실제 통과 가능 여부는 직접 클리어해 확인합니다.
