# DEV NOTES

> 프로그래머 관리. 기술 규약과 임시 값만 짧게 적는다. 기획 내용은 `GDD.md`.

## 기술 규약
- Full HD(1920×1080), URP 2D, Pixel Perfect Camera
- 스프라이트: 캔버스 64×64, PPU 64, Filter Point, Compression None
- 기준 해상도: 640×360 (3배, 캐릭터가 화면 높이의 1/5.6). 카메라 y=0.703125 (바닥을 화면 하단에 맞춤)
- 월드 구조: 플레이어는 화면 고정, `Stage`(kinematic)가 왼쪽으로 스크롤
- 입력: `RunnerInput`에서 코드로 정의 — 점프 Space/↑/W, 슬라이드 S/↓, 감속 LeftShift
- `Assets/Placeholders/`: 임시 사각형 스프라이트. 실제 아트 연결 후 삭제

## 임시 값 (기획 확정 시 삭제)
- 속도 조절: 기준 속도가 계속 증가(4 + 0.1/s²) + 감속 키, 키를 떼면 기준 속도로 복귀 (GDD 미정 목록에서 빠졌으나 방식은 미기재)
- 2단 점프(GDD 3장): 2번째 점프 높이 1.2 (1단 1.8). 공중에서는 속도를 현재 값으로 유지하고 `SpeedController.AirControl`이 true일 때만 조절 (마녀 비행 구현 시 사용)
- GDD와 구현 차이: 캐릭터 크기 1/5.6 (GDD 1/4.5)- 점프 높이 1.8, 중력 배율 2 (체공 0.86초), 슬라이드 시 충돌 높이 50%
- 가시(높이 0.5) 위 체공: 1단 0.73초, 2단 최대 1.43초. 폭 w를 넘는 최소 속도 ≈ (w + 0.5) ÷ (체공 − 0.15)
  - 1단만: w=2.5에 5.2, 2단 사용: w=5에 4.3, w=7에 5.9
- 움직이는 장애물(Gate): 주기 3초, 닫힘 약 43%. 감속으로 도착 타이밍을 늦춰 통과
- 추격자: 속도 4.5, 시작 거리 8, 잡히는 거리 1.25 (스테이지별 조정 예정). 사망 후 0.8초 뒤, 클리어 2.5초 뒤 스테이지 처음부터 재시작 (체크포인트 없음)
- 재시작 시 속도·기준 속도·스테이지 시간(Gate 타이밍)을 시작 값으로 복원
- 추격자 발소리 소리는 미구현 (`Chaser.Proximity`로 볼륨 연결 예정), 진행 막대바는 임시 IMGUI
- 테스트 씬: `TestStage`(기본 점프/슬라이드), `TestStage_Speed`(속도 기믹)
