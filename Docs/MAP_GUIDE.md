# 맵 디자인 가이드 (초보자용)

> 맵 디자이너용. Unity를 처음 써도 따라 할 수 있게 적었다. 값은 아직 직접 플레이 테스트를 거치지 않은 임시 값이라 바뀔 수 있다.

## 0. 시작 전에

1. Git에서 최신으로 pull 한다. Unity 버전은 **6000.3.20f1**이다.
2. Unity로 프로젝트를 연다. 위쪽 메뉴 바(File, Edit, Assets, GameObject, Component …)에 **Plum** 메뉴가 보이면 준비 완료다. 안 보이면 Unity 창을 한 번 클릭하거나 Ctrl+R(Refresh)을 누른다.

### 내가 만지는 것 / 만지지 않는 것

| 만져도 되는 것 | 만지면 안 되는 것 |
|---|---|
| 내 `Assets/Prefabs/Maps/Map_내이름.prefab` | `Assets/Prefabs/StageRig.prefab` |
| 내 `Assets/Scenes/Stage_내이름.unity` | `Assets/Prefabs/Palette/`의 원본 조각 |
| | `Assets/Scripts/`, `ProjectSettings/` |
| | 다른 사람의 `Map_*`, `Stage_*` |

원본을 고쳐야 할 것 같으면 직접 고치지 말고 프로그래머에게 말한다.

## 1. 새 스테이지 만들기

1. 메뉴 **Plum > New Stage**를 연다.
2. 이름을 입력하고 **만들기**를 누른다. 영문/숫자로 쓰고 공백은 쓰지 않는다. 예: `Forest1`
3. 아래가 자동으로 만들어진다.
   - 씬 `Assets/Scenes/Stage_Forest1.unity`
   - 맵 프리팹 `Assets/Prefabs/Maps/Map_Forest1.prefab` (바닥 170 + Goal이 들어 있음)
   - 이동 스냅 0.5 켜짐

## 2. 맵 편집 화면 열기

1. Hierarchy(왼쪽 목록)에서 `StageRig` > `Stage` > `Map_Forest1`을 찾는다.
2. `Map_Forest1`을 **더블클릭**한다. 화면이 Prefab 모드로 바뀌고 맵 조각만 보인다. 여기서 작업한다.
3. 작업이 끝나면 Hierarchy 위쪽의 **← 화살표**로 나온다. 바뀐 내용은 저장해야 한다 (Ctrl+S, 또는 Prefab 모드 위쪽의 **Auto Save** 체크).

## 3. 조각 배치하기

`Assets/Prefabs/Palette/`에서 조각을 **Hierarchy의 `Map_Forest1` 위로 끌어다 놓는다.** 그러면 `Map_Forest1`의 자식으로 들어가고 바닥에 맞는 기본 높이로 생긴다. Scene 화면에 바로 끌어다 놓으면 높이가 어긋나거나 `Map_Forest1` 밖에 생길 수 있다.

놓은 뒤 Inspector의 **Position Y**가 아래 표와 같은지 확인한다 (표에 없는 값이면 고친다).

| 조각 | Position Y |
|---|---|
| Spike, Block(바닥) | -0.86 |
| Bar, Block(매달기) | -0.26 |
| 소형화 통로용 Block (Scale Y 0.5) | -0.46 |
| Gate | 2.19 |
| Item_* | -0.61 |
| Goal | 1.39 |
| Ground | -1.61 |

| 조각 | 뜻 | 크기 조절 |
|---|---|---|
| Ground | 바닥. 길이 20 | 이어 붙인다 (x 간격 20) |
| Spike | 가시. 닿으면 사망. **점프해서 넘는다** | Scale X = 폭, Scale Y는 0.5 유지 |
| Bar | 공중에 뜬 막대. 닿으면 사망. **슬라이드로 밑을 지나간다** | Scale X = 폭 |
| Gate | 위아래로 움직이는 벽. 내려와 있을 때 닿으면 사망. **타이밍을 보고 감속해서 통과**. 파괴할 수 없다 | Inspector의 Period(주기), Phase(시작 타이밍) |
| Block | **파괴 불가 장애물.** 닿으면 사망. 거대화 중에도 못 부순다. 크기와 배치는 Spike, Bar와 같게 쓴다(스프라이트만 다를 예정) | Scale X = 폭 |
| Item_Giant | **거대화 아이템.** 5초 동안 커진다. 커진 동안 Spike, Bar에 닿으면 부수고 지나간다 (Block, Gate는 못 부숨) | 위치만 옮긴다 |
| Item_Small | **소형화 아이템.** 5초 동안 작아진다. 슬라이드보다 낮은 틈(높이 0.4 이하)을 지나갈 수 있다 | 위치만 옮긴다 |
| Item_Boost | **가속 아이템.** 2초 동안 속도가 +4 빨라진다. 넓은 가시를 넘거나, 반대로 너무 빨라서 죽는 구간에 쓴다 | 위치만 옮긴다 |
| Goal | 닿으면 클리어. 스테이지 끝에 **하나만** | 위치만 옮긴다 |

Spike, Bar는 파괴 가능이고 Block, Gate는 파괴 불가다. 아이템 지속 시간과 수치는 임시 값이다.

### 퍼즐 설계 팁

이 게임은 **시행착오로 푸는 퍼즐**이다. 어떤 속도로 갈지, 아이템을 먹을지 말지, 비행을 언제 쓸지에 따라 클리어 여부가 갈리게 만든다.
- 아이템은 **안 먹고 지나갈 길**도 있게 두면 선택이 된다. 먹어야만 깰 수 있는 곳도, 먹으면 오히려 못 깨는 곳(거대화하면 Gate 앞에서 사망, 가속하면 짧은 구간에서 사망)도 만들 수 있다.
- 아이템은 죽으면 다시 나타난다. 먹은 아이템 효과도 재시작하면 사라진다.
- 소형화 전용 통로는 위에 Block을 매달아 만든다. 바닥에서 Block 아래까지의 틈을 **0.4**로 하면 일반 슬라이드(0.45)는 못 지나가고 소형화만 지나간다. 예시는 `Map_Gimmicks`를 연다.

### 위치 옮기기
- Scene 화면에서 조각을 클릭하고 **빨간 X 화살표**를 좌우로 끌면 0.5씩 움직인다. **Y(초록 화살표)는 건드리지 않는다.** 위 표의 높이가 바닥에 맞는 값이다.
- 정확한 값은 오른쪽 Inspector의 **Transform > Position X**에 숫자를 직접 입력한다.
- 폭 바꾸기는 Inspector의 **Scale X**에 입력한다 (가시 폭 5 = Scale X 5).

### 좌표 감각
- 1유닛은 캐릭터 한 칸 정도(64px)다. 화면은 가로 10, 세로 약 5.6유닛이다.
- 플레이어 시작 위치는 **x = -2**다. 맵은 오른쪽(+x) 방향으로 만든다.
- 감속 없이 달릴 때 대략 이 위치에서 그 순간이 온다.

| 시작 후 | 맵 x 위치 | 그때의 속도 |
|---|---|---|
| 10초 | 약 43 | 5 |
| 20초 | 약 98 | 6 |
| 30초 | 약 163 | 7 |

## 4. 속도 설정

루트 `Map_Forest1`을 선택하고 Inspector의 **Stage Settings**에서 조정한다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| Start Speed | 4 | 시작 속도 |
| Acceleration | 0.1 | 초당 빨라지는 정도 |
| Chaser Speed | 4.5 | 쫓아오는 쿠키 속도 (일정) |
| Chaser Start Gap | 8 | 시작할 때 쿠키와의 거리 |

- **배경 선택**: 같은 Inspector의 **배경 선택** 팝업에서 산, 사막, 묘지, 눈 중에서 고른다. 선택한 배경은 Play할 때 나타난다 (Prefab 모드에서는 보이지 않는다). "(없음)"을 고르면 배경이 없다.
- Inspector 아래쪽 **맵 검증**에 Goal 유무, 시작 바닥, 예상 시간(목표 30초)이 나온다. 빨간 오류는 반드시 고친다.
- 쿠키 속도가 내 속도보다 느리면 감속하지 않는 한 안 잡힌다. 그래서 속도를 너무 낮게 시작하면 쿠키가 따라잡는다. 감속하면서 플레이해 보며 맞춘다.

### 가시 폭과 필요한 속도 (참고)
점프 거리는 속도에 비례한다. 가시 높이는 0.5다.

| 가시 폭 | 필요한 최소 속도 | 방법 |
|---|---|---|
| 2.5 | 약 5.2 | 1단 점프 |
| 5 | 약 4.3 | 2단 점프 |
| 7 | 약 5.9 | 2단 점프 (이보다 넓으면 못 넘는다) |

## 5. 테스트하기

1. Prefab 모드에서 나와 저장한 뒤 **Play(▶)**를 누른다.
2. 조작: 점프 `Space`/`↑`/`W` (공중에서 한 번 더 누르면 2단 점프), 슬라이드 `S`/`↓`, 감속 `Left Shift`, 비행 `E`(스테이지당 1회, 5초).
3. 죽으면 약 1초 뒤 처음부터 다시 시작한다. 체크포인트는 없다.
4. Scene 화면에는 **초록 선**(플레이어 시작 위치)과 **회색 박스**(첫 화면 범위)가 보인다.

## 6. 주의점 (꼭 읽기)

1. **Play 중에 바꾼 값은 Play를 끄면 사라진다.** 값을 조정하고 싶으면 Play를 끈 뒤에 바꾼다.
2. **Inspector에서 Overrides > Apply All을 누르지 않는다.** 팔레트 조각의 Scale이나 위치를 바꾼 뒤 Apply를 누르면 원본 팔레트가 바뀌어 모든 사람의 맵이 망가진다. Scale을 바꾸기만 하고 그대로 둔다.
3. **팔레트 폴더의 조각을 더블클릭해서 열지 않는다.** 원본이다.
4. **`StageRig`를 수정하지 않는다.** 위치를 옮기거나 지우면 게임이 안 돌아간다. 내 일은 `Map_내이름` 안에서 끝난다.
5. **바닥이 끊기면 구멍이다.** 플레이어가 6유닛 이상 떨어지면 사망한다. 구멍을 일부러 만들 때는 점프로 넘을 수 있는 폭인지 확인한다. 시작 위치(x=-2)에는 반드시 바닥이 있어야 한다.
6. **Goal은 하나만, 맨 끝에.** Goal 뒤에도 바닥이 조금 있어야 한다. Goal이 없으면 클리어가 안 된다.
7. **시작 직후는 비워 둔다.** 처음 10유닛 정도는 장애물을 두지 않는다. 플레이어가 상황을 파악할 시간이 필요하다.
8. **깰 수 없는 배치를 만들지 않는다.** 가시 폭이 너무 넓거나, 가시와 막대가 붙어서 점프와 슬라이드를 동시에 해야 하면 못 깬다. 만든 뒤 반드시 내가 직접 클리어해 본다.
9. **스테이지 길이는 감속 없이 30초 정도**를 목표로 한다. 맵 검증의 예상 시간을 본다.
10. **Z 값은 0으로 둔다.** 조각이 안 보이거나 충돌이 안 되는 원인이 된다.
11. **빈 곳에 조각을 놓지 않는다.** `Map_내이름`의 자식이 아니면 맵이 스크롤될 때 같이 움직이지 않고 제자리에 있다. Hierarchy에서 들여쓰기를 확인한다.
12. Undo는 **Ctrl+Z**다. 실수하면 바로 되돌린다.

## 7. 저장하고 올리기 (Git)

- 올릴 파일은 **내 것만**이다. `.meta` 파일도 같이 올린다 (없으면 연결이 끊어진다).
  - `Assets/Scenes/Stage_이름.unity`, `.meta`
  - `Assets/Prefabs/Maps/Map_이름.prefab`, `.meta`
- 작업 전에 항상 pull, 큰 변경 전에는 commit 한다.
- 다른 사람의 맵 파일이 충돌로 보이면 건드리지 말고 프로그래머에게 알린다.

## 8. 문제가 생기면

| 증상 | 확인 |
|---|---|
| Plum 메뉴가 없다 | Unity 창 클릭 또는 Ctrl+R. 안 되면 Console의 빨간 에러를 프로그래머에게 보여 준다 |
| Play 했는데 캐릭터가 바로 떨어진다 | 시작 위치(x=-2) 바닥, 맵 검증 오류 확인 |
| 조각이 화면에서 안 보인다 | Z=0인지, `Map_내이름` 자식인지 확인 |
| Gate가 안 움직인다 | Play 중인지 확인 (Prefab 모드에서는 움직이지 않는다) |
| 클리어가 안 된다 | Goal이 하나 있는지, 맵 검증 확인 |
| 값을 바꿨는데 반영이 안 된다 | Play를 끄고 바꿨는지, 저장했는지 확인 |

앞으로 트램펄린, 부서지는 발판 같은 새 기믹이 생기면 팔레트에 조각이 추가된다.
